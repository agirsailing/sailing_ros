# Guide

_Aggiornato al giorno: 30/10/2026_

[English](README_ENG.md)

Questa cartella raccoglie le guide per preparare l'ambiente di lavoro e collegarsi al sistema di bordo.

## Da dove iniziare

1. Installa gli strumenti elencati nella [guida ai software necessari](italiano/software_necessari.md).
2. Clona la repository sul tuo computer eseguendo questo comando nel terminale:

   ```bash
   git clone https://github.com/agirsailing/sailing_ros.git
   ```

Dopo questi passaggi, scegli la guida in base all'attività che devi svolgere.
