# Guides

_Updated on: 30/10/2026_

This folder collects guides for setting up the development environment and connecting to the onboard system.

## Where to start

1. Install the tools listed in the [required software guide](software_necessary.md).
2. Clone the repository to your computer by running this command in a terminal:

   ```bash
   git clone https://github.com/agirsailing/sailing_ros.git
   ```

After these steps, choose the guide for the task you need to carry out.

## Available guides

| Purpose | Guide |
|---|---|
| Connect to the onboard Raspberry Pi. | [Raspberry Pi connection](raspberry_connection.md) |
| Set up the development environment on your computer. | [PC setup](pc_setup.md) |
| Prepare and configure the Raspberry Pi for the onboard system. | [Raspberry Pi setup](raspberry_setup.md) |
| Start the ROS system on the Raspberry Pi and use debugging commands. | [ROS system startup](ros_system_startup.md) |
